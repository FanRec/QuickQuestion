# QuickQuestion 开发计划

> 桌面悬浮球 AI 问答工具。常驻桌面 → 提问 → 流式作答 → 沉淀为可回溯、可复制为 Markdown 的本地历史。
> 本文档是全局基线；每个里程碑另有 `docs/Mn-design.md` 详细设计。

## 1. 需求锁定（2026-11-17 确认）

| 项 | 决定 |
|---|---|
| 悬浮球 | 主球（点击展开聊天栏）+ 左侧小球（点击展开悬浮列表） |
| 聊天栏 | **只有一个输入框**；答案在输入框上方临时气泡流式显示，完成后保留片刻自动收起 |
| 悬浮列表 | 全部问答；每条右侧两按钮：展开详情、复制 |
| 主窗口 | 普通软件形态：左问题列表 + 右完整问答；顶部最小化/全屏/关闭 + 设置/帮助 |
| 复制格式 | `## 问题\n回复`；图片以 `[图片1]` 占位 |
| DeepSeek 接入 | 网页版 CDP（零 API Key，复用登录态；接受 ToS/风控与网页改版脆弱性） |
| 前端风格 | 苹果风格（毛玻璃、圆角、SF 字体栈、克制动效、明暗双主题） |

## 2. 技术栈（社区调研定稿）

| 层 | 选型 | 依据 |
|---|---|---|
| UI 壳 | Tauri 2 + React 19 + TypeScript + Vite | 空闲内存 30–68MB vs Electron 165–200MB；同类悬浮 AI 项目（Pluely/栖伴/LazyWords）均选 Tauri 2 |
| 后端 | Rust（tauri command + tokio） | CDP WebSocket、SQLite、系统能力同栈，无跨语言边界 |
| 浏览器驱动 | 独立 Edge/Chrome + `--remote-debugging-port=9222` + 专用 profile | 复用登录态、CDP 标准能力、与 UI 进程解耦 |
| 流式 | 注入 MutationObserver + 完成状态机 | 网页版准实时流式；优于参考项目的 300ms 轮询 + 7 次稳定判定 |
| 存储 | SQLite（rusqlite） | 单一数据源，三视图共享 |
| Markdown | markdown-it（前端） | 轻量、可扩展 |
| 剪贴板 | tauri-plugin-clipboard-manager | 复制问答 |
| 图标 | tauri icon 生成 | 苹果风格圆角方形 |

## 3. 架构原则

1. **单一数据源**：SQLite 是历史的唯一真相；悬浮列表、主窗口左栏、详情面板全部通过 IPC 命令读取，前端不持有副本。
2. **窗口即视图**：四种界面是四个独立 Tauri 窗口（orb/chat/history/main），不是单页内的状态切换；这样透明、置顶、可拖拽等窗口属性可独立配置。
3. **进程解耦**：DeepSeek 网页跑在独立 Edge 进程；UI 崩溃不影响浏览器，浏览器崩溃可重连。
4. **类型化边界**：前端与 Rust 之间的 IPC 命令有明确的 TypeScript 类型对应，事件有统一 envelope。
5. **最小依赖**：M0 只装骨架依赖，其余按里程碑需要引入；不引入 Playwright 等重型依赖。

## 4. 里程碑与退出标准

每个里程碑严格循环：**开工前详细设计 → 实现 → 代码审查与重构 → git 提交 → 下一块**。

| 里程碑 | 范围 | 退出标准（验收） | 依赖 |
|---|---|---|---|
| **M0** 骨架与设计系统 | git init、Tauri+React 初始化、目录结构、苹果 tokens、四窗口声明 | `npm run tauri dev` 启动，orb 显示主球+小球，无控制台错误，已提交 | — |
| **M1** 四窗口形态 | 悬浮球拖拽置顶、极简聊天输入框、悬浮列表、主窗口左右布局 | 四窗口可展开/收起/拖拽，视觉符合苹果风格，已提交 | M0 |
| **M2** CDP 内核 | BrowserManager（启动/复用 Edge）、CdpClient（连接/evaluate/导航/输入框探测） | 集成测试能连接浏览器并读取 DeepSeek 页面 URL，已提交 | M1 |
| **M3** 发送与流式 | 文字发送、MutationObserver 逐块回传、完成状态机、取消、图片上传 | 端到端发一条文字流式显示并落库，图片可上传，已提交 | M2 |
| **M4** 历史与三视图 | SQLite schema/CRUD、IPC 命令、列表/详情联动、复制格式 | 问答落库、三视图联动、复制格式正确，已提交 | M3 |
| **M5** 设置帮助与控件 | 设置持久化、帮助、最小化/全屏/关闭、托盘 | 设置可持久化，窗口控件行为正确，已提交 | M4 |
| **M6** 联调与健壮性 | 未登录/验证码/改版/断连兜底、日志、端到端验收 | 验收清单逐项通过，全量构建成功，最终提交 | M5 |

## 5. 风险登记

| 风险 | 概率 | 影响 | 应对 |
|---|---|---|---|
| DeepSeek 网页改版导致选择器失效 | 高 | 高 | 选择器集中配置为常量 + 多候选 fallback + 明确的诊断提示；M6 提供"显示网页会话"手动检查 |
| 账号风控/验证码 | 中 | 高 | 专用 profile、随机发送间隔、验证码检测后锁定输入并提示人工处理 |
| 远程调试端口无鉴权 | 固定 | 中 | 绑定 127.0.0.1、专用 profile、文档提示勿在共享机器使用 |
| Tauri 透明窗口平台差异 | 中 | 中 | `transparent:true` + `shadow:false` + 必要时 `set_background_color`；M1 逐窗口实测 |
| WebView2 拖放需先合成 | 中 | 低 | 窗口 `visible:true` 但停在屏幕外（M1 处理） |
